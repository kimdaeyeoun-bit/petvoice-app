# LUMINA — AI Cinema & Festival

AI 영화 상영관, 온라인 출품전과 제작 자료실을 갖춘 실행 가능한 웹 앱입니다. 한국어 UI, 아이보리·딥그린 디자인과 모바일 레이아웃을 제공합니다.

## 미리보기와 웹 배포

다운로드해서 열 수 있는 `preview/LUMINA-preview.html`과 Render용 `render.yaml`을 제공합니다. 자세한 안내는 [DEPLOY.md](DEPLOY.md)를 보세요. 미리보기는 브라우저에만 저장되며 실제 서버 계정과 연결되지 않습니다. `npm run release:build`로 미리보기와 소스 ZIP을 다시 만들 수 있습니다.

## 실행

Node.js 24 이상이 필요합니다. 현재 환경에는 Node.js 24.19.0과 Chromium이 설치되어 있습니다.

```sh
cd /workspace/petvoice-app
npm ci
npm start
```

기본 포트는 3000입니다. `PORT`와 `HOST`로 변경할 수 있습니다. 프런트엔드와 API는 같은 서버에서 제공합니다. 별도의 빌드나 외부 데이터베이스, API 키는 필요하지 않습니다. 코드를 자동 다시 실행하려면 `npm run dev`를 사용하세요.

## 구현 기능

- 직접 생성하는 앰비언트 음악과 저음 터치·전환음: 개별 설정, 볼륨 조절, 영상 재생 중 음악 정지
- 작품 탐색: 장르 필터, 제목·영문 제목·감독·설명 검색, 최신·추천·투표순 정렬
- 실제 HTML5 영상 감상 및 업로드 영상의 HTTP Range 구간 재생
- 회원가입, 비밀번호 해시, 로그인·로그아웃, HttpOnly 세션과 프로필 수정
- MP4 파일 업로드(100MB 제한) 또는 공개 HTTPS 영상 직접 주소로 출품
- 포스터, 소개, 장르, 상영 시간, AI 도구와 제작 노트 등록
- 작품별 관객 투표와 취소, 찜과 해제, 개인 상영관
- 제작자별 작품 목록과 소개
- 데모 특별 상영권 발급, 이용 권한, 후원 기록 및 80:20 수익 배분
- 거래 내역, 제작자의 데모 누적 수익 확인
- 직접 작성한 제작 가이드 9개: 검색, 상세 읽기와 관련 공식 문서 링크

샘플 6편의 제목·설명·제작자는 가상입니다. 작품 정보에는 이를 표시하며 모든 샘플은 같은 Big Buck Bunny 클립을 재생합니다. 회원이 직접 출품한 작품은 샘플과 구분되고 실제 제공한 영상으로 재생됩니다. 포스터는 이 프로젝트에서 제작한 SVG입니다.

## 데이터와 설정

데이터는 기본적으로 `.runtime/cinema.sqlite`, 영상은 `.runtime/uploads/`에 저장됩니다. 서버를 재시작해도 유지되며 Git에서는 제외합니다. 보관할 경우 데이터베이스와 영상 디렉터리를 함께 백업하세요. `DATA_DIR`에 별도 데이터 경로를 지정할 수 있습니다. 테스트는 독립된 임시 데이터베이스를 사용합니다.

`COOKIE_SECURE=1`은 HTTPS 배포 시 Secure 쿠키를 활성화합니다. HTTP 로컬 개발에서는 지정하지 마세요. 서비스는 계정 인증에 이메일 소유 확인을 요구하지 않습니다. 초기 관리자 계정이나 공용 테스트 비밀번호를 만들지 않습니다.

## 검증

```sh
npm run check
npm test
npm run test:browser
npm run test:sound
npm run test:studio
```

API 테스트 7개가 회원, 출품, 권한, 투표, 찜, 데모 거래, 수익 배분, 프로필, 업로드 소유권, 구간 재생과 교차 출처 요청 차단과 재시작 후 데이터 보존을 검증합니다. 브라우저 테스트는 Playwright와 시스템 Chromium을 사용하며 필요하면 `CHROMIUM_PATH`를 지정하세요. 실제 MP4 업로드·재생, 검색, 투표, 데모 상영권, 거래 내역, 프로필·제작자, 자료실과 모바일 가로 넘침을 검증합니다. 화면 캡처는 `.runtime/screenshots/`에 생성됩니다.

## 실제 운영 전에 필요한 연결

현재 결제·후원은 **데모 거래**입니다. 카드 정보, 실제 청구, 송금이나 정산을 수행하지 않습니다. 실제 매출을 받으려면 결제 사업자 계약·키와 서버 결제 검증·웹훅·환불·정산 처리가 필요합니다. 데모 거래 기록을 실제 지급 의무가 있는 금액으로 해석하면 안 됩니다.

영화제는 상시 출품과 관객 투표 기능을 제공합니다. 공식 심사·수상·마감 일정 기능은 아직 없습니다. 서비스 출시 전 운영자 심사·신고 처리, 저작권 검토, 이메일 인증·계정 복구, 개인정보·이용약관, HTTPS 배포, 트래픽 제한, 백업·모니터링 및 대용량 영상 저장소·인코딩을 준비해야 합니다. 현재 파일 검사는 MP4 컨테이너 서명과 용량을 검사하며 전체 디코딩·보안 검사를 대체하지 않습니다.

공개 HTTPS 영상·포스터 URL은 해당 출처에서 접근할 수 있어야 합니다. 기본 샘플과 포스터는 로컬 파일이므로 실행 중 외부 네트워크가 필요 없습니다. 실제 영상과 인터뷰 자료를 확보하려면 제작자의 출품 또는 이용 허락이 필요합니다.

## 사운드

오른쪽 아래 **사운드 켜기**를 누르면 오리지널 생성 음악이 시작됩니다. 설정 버튼에서 음악·효과음을 개별 선택하고 볼륨을 조절할 수 있습니다. 자동 재생하지 않으며 영상 감상 중과 숨겨진 탭에서는 음악을 정지합니다. 설정은 브라우저에 저장하지만 새로 열 때 재생은 다시 선택해야 합니다. Web Audio API가 필요하며 외부 음원이나 네트워크는 사용하지 않습니다.

## 글로 영화 만들기

제작실에서 원문(최대 4,000자), 작가의 의도, 연출 방향과 분위기를 입력합니다. 기본 장면 구성은 원문을 문장·문단 단위로 나누는 로컬 규칙이며 AI 해석으로 표시하지 않습니다. 최대 8장면의 글, 화면 설명, 순서와 길이(2~12초)를 수정할 수 있습니다. 프로젝트는 비공개로 계정에 저장하거나 JSON으로 내려받을 수 있습니다.

현재 바로 사용할 수 있는 **스토리보드 영상**은 Canvas의 절차적 도시·바다·숲·우주 배경, 느린 움직임, 원문 자막과 오리지널 음악으로 구성됩니다. 실제 인물·배우를 생성하는 AI 실사 영화가 아닙니다. Chrome의 MediaRecorder로 720p MP4 또는 WebM을 실제 생성하며 영상 길이만큼 시간이 필요합니다. 창을 전면에 둔 상태로 제작하세요. WebM도 상영관 출품·재생을 지원합니다. 최종 감상·승인·상영 권리 확인 없이 출품하지 않습니다. 로컬 결과 파일은 새로고침 전 다운로드해야 합니다. JSON 초안은 영상을 포함하지 않습니다.

### 외부 AI 영상 생성 연결

OpenAI 공식 SDK의 영상 API 명세에 맞춘 Sora 테스트 클립 생성 어댑터를 제공합니다. 유효한 영상 API 권한·잔액이 있는 서버 측 키가 필요합니다. **실서비스 생성은 키가 없어 검증하지 않았습니다.** 자동 테스트는 로컬 모의 공급자로 인증·작업 상태·비공개 결과·승인과 출품을 검증합니다. 다운로드 HTML은 외부 AI를 호출하지 않습니다.

배포 서버의 보안 환경 설정에 `VIDEO_API_KEY`를 넣고, `VIDEO_ALLOWED_EMAILS`에 생성 권한을 줄 회원 이메일을 쉼표로 나눠 등록한 뒤 `VIDEO_GENERATION_ENABLED=1`로 활성화합니다. 기본은 꺼져 있으며 `VIDEO_DAILY_LIMIT`은 계정당 최근 24시간 요청 수를 제한합니다(기본 3, 최대 10). 키는 브라우저·프로젝트 파일·Git에 넣지 마세요. Render에서도 Environment 설정을 사용하세요.

AI는 승인한 전체 장면 설명을 바탕으로 4·8·12초짜리 **한 개의 테스트 클립**을 생성합니다. 여러 장면을 각각 생성·연결하는 장편 파이프라인, AI 내레이션, 자동 리립싱크·결제 크레딧 기능은 포함하지 않습니다. AI 테스트 클립의 실제 결과와 일관성은 모델에 따라 달라집니다. 생성 전에는 제공 서비스의 현재 요금을 확인하고 비용·권리를 별도로 승인합니다. 사이트 데모 결제는 이 실제 API 비용을 충당하지 않습니다.

생성 결과는 `.runtime/studio-private/`에 비공개로 보관하며 소유자만 감상할 수 있습니다. 최종 승인 이후에만 출품용 영상 경로로 복사됩니다. 사용자의 실패한 요청도 일일 한도에 포함하며 자동 재요청으로 비용을 늘리지 않습니다. 같은 요청 ID의 중복 제출은 한 번만 생성합니다.

### 제작·수익 관리

새 `제작·수익` 메뉴에서 저장한 글의 제작 신청, 관리자 검토, 무료 예고편 승인, 본편 견적·데모 결제, 최종 승인·공개를 진행합니다. 상영권·후원은 창작자 80%로 배분하고, 관리자 확정 후 5만 원부터 데모 지급을 신청합니다. 조회수는 실제 관람 통계이며 그 자체로 돈을 만들지 않습니다. 다운로드 미리보기는 로그인 후 `관리자 모드 체험`으로 전체 제작 흐름을 확인할 수 있습니다. 서버 관리자 설정과 실제 서비스 연결에 필요한 사항은 DEPLOY.md를 참고하세요.

## 원작 도서관 · 창작자와 독자의 공간

`원작 도서관`에서 글·시·시나리오·웹툰·만화를 무료로 등록합니다. 영상이나 AI 상품을 구매할 필요가 없습니다. 작품별 대표 표지와 공개·비공개 회차를 관리하고, 기존 본인 출품 영화와 HTTPS 소개 영상을 같은 작품에 연결합니다. `창작자 작업실`에서는 자기 작품과 기초 반응을 보고, `내 책장`에서는 팔로우한 작가의 새 회차 알림과 저장한 작품을 확인합니다. 작품에서 읽던 회차와 위치를 이어갈 수 있습니다.

관리자는 `콘텐츠 운영`에서 작품 숨김·복원·편집부 추천·신고 처리·기초 통계를 확인합니다. 서버는 `ADMIN_USER_IDS`로 제한합니다. 다운로드 HTML에서는 로그인 후 `제작·수익`의 관리자 모드 체험을 명시적으로 켠 경우에만 운영 화면을 체험합니다. 원문 비공개와 회차 비공개는 각각 적용되며, 외부 이미지 주소의 공개 범위는 외부 서버 설정에 따릅니다.

`개발 단계표`와 [ROADMAP.md](ROADMAP.md)는 63개 요구사항의 단계·완료 조건·검증 근거를 추적합니다. [OPERATIONS.md](OPERATIONS.md)는 운영·홍보·백업·장애 대응 순서입니다. `npm run roadmap:check`로 누락과 증거 파일을 검사하고, `npm run test:community`로 실제 서버와 단일 HTML 미리보기의 등록·독자·운영자 흐름을 검증합니다. GitHub Actions 설정도 포함되어 있지만 집 서버의 상시 감시나 자동 배포는 아닙니다.

현재 원작 데이터 저장은 소규모 검증용 SQLite JSON 상태입니다. 대량 운영에 앞서 관계형 테이블·이미지 저장소·색인·부하 검증으로 확장해야 합니다. 실제 AI 표지·웹툰 자동 생성, 유료 책·웹툰 구매, 실결제·송금, 공식 영화제 심사·수상, 외부 자동 홍보, 이메일·푸시는 완료 기능으로 표시하지 않습니다.
